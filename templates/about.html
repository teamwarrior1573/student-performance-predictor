About Project

Project Title:
Student Performance Predictor Using Machine Learning

This is a professional AI based web application developed to predict student academic performance using real-world educational factors. The system uses Machine Learning to analyze student data and estimate final exam score.

Main Objective:
To help students, teachers, and institutions identify academic performance trends, understand weak areas, and improve future results through data-driven insights.

Main Features:
• Multi-step modern form system
• Fast prediction engine
• Kaggle real dataset based training
• Professional futuristic UI
• Instant score + grade result
• About page and navigation system

Input Factors Used:
Hours Studied
Attendance
Previous Scores
Tutoring Sessions
Sleep Hours
Physical Activity
Internet Access
Parental Involvement
Motivation Level
Teacher Quality
Family Income
School Type

Technology Stack:
Frontend: HTML, CSS, JavaScript
Backend: Python Flask
Machine Learning: Random Forest Regressor
Libraries: Pandas, NumPy, Scikit-learn, Joblib

Working Process:
1. User enters personal details.
2. User fills academic and lifestyle data.
3. Data sent to Flask backend.
4. Trained ML model predicts score.
5. Final result shown instantly.

Advantages:
• Accurate and smart predictions
• Easy to use interface
• Helps in academic planning
• Saves time for analysis
• Realistic AI project for education

Future Scope:
Can be upgraded with login system, dashboard analytics, prediction history, PDF report download, mobile app version, charts and recommendations.
